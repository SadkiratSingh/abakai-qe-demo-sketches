How a rule is linked

  1. The Failure Library has a path: rule → mechanism → defect. Rules with OR are split into unit rules joined only by AND.
  2. Boards where the rule condition is true are compared with boards where it is false:
    • Defect rate, rule condition true vs false: 2× or more
    • Fisher's exact test: p < 0.01
    • Boards with the defect where the rule condition was true: 20% or more
Linked: passes all three. Contributing: passes the first two, and the mechanism's passing rules together reach 20%.
Measurements such as SPI paste volume are never root causes; they show as evidence for a mechanism.
